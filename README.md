# AutoPatch – Local Autonomous Debugging System (Round-1 Submission)

## Overview
AutoPatch is a **fully local, deterministic, rule-based autonomous debugging system**  
built to satisfy all Round-1 requirements of the Debugging Hackathon.

It performs:

- Sandboxed execution  
- Error extraction  
- Patch rule matching  
- Autonomous multi-iteration repair  
- Patch logging  
- Final code generation  

LLMs are **not used** in Round-1 (per rules and reliability requirements).

---

## Features
### ✔ Local sandboxed execution  
### ✔ Error → Patch mapping  
### ✔ Rule-based patching  
### ✔ Automated repair loop  
### ✔ Max-iteration control  
### ✔ Test suite included (10 bug files)  
### ✔ Works entirely offline
